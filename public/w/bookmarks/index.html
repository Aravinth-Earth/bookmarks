Bookmarks

One vault, sealed in this browser. The server holds a sealed copy and an account record, never a bookmark.

Ticking this stores this vault's key and a sign-in secret in this browser for a month, so it can reopen the vault without the phrase. The key cannot be read out by a script, but a copied browser profile can use it. Unticked, the phrase is asked for on every open.

There is no recovery. The phrase is the only key: lose it and the vault cannot be opened by anyone, including whoever runs this server.

No room for a new account

This server has a fixed number of vault spaces and all of them are in use, so it cannot create a new account. Write to feedback@8alias.com to ask for one; this vault keeps working on this device.
